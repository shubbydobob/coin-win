# ADR 006 — 실시간 뉴스 알림을 구현하지 않는다

- 상태: 채택
- 날짜: 2026-08-21

## 맥락

매크로 이벤트(FOMC, CPI, 국채 관련 발표)는 BTC 가격에 크게 반영된다.
"뉴스를 수집해 알림을 주면 대응할 수 있지 않겠는가"가 자연스러운 요구다.

## 결정

**실시간 뉴스 수집·감성분석·알림을 구현하지 않는다.**

## 근거

### 경로가 구조적으로 늦다

```
헤드라인 수집 → 파싱 → 알림 → 인간 판단 → 수동 진입
```

매크로 발표가 가격에 반영되는 시간은 분 단위, 때로는 초 단위다.
위 경로의 각 구간이 초를 먹고, 마지막 두 구간(인간 판단, 수동 진입)은 압축할 수 없다.
알림이 도착했을 때는 이미 반영이 끝나 있다.

### 인과 연결이 감성분석으로 도출되지 않는다

"국채 바이백 확대 → 유동성 기대 → 위험자산 상승" 같은 연결은 헤드라인의 긍/부정 점수에서
나오지 않는다. 이건 감성이 아니라 거시 경로 추론이다.
감성분석이 내놓는 것은 "이 헤드라인은 긍정적" 정도이고, 그것으로는 방향을 정할 수 없다.

### 이 프로젝트가 푸는 문제가 아니다

`scope.md` 는 이 프로젝트의 문제를 둘로 못박았다.

1. 분할 진입 시 총 리스크를 진입 전에 파악할 수 없다
2. 매매 이력이 구조화되지 않아 사후 분석이 불가능하다

뉴스 알림은 둘 중 어느 쪽에도 기여하지 않는다.

## 대안

**예정 이벤트 캘린더** (FOMC, CPI 등). 예측이 아니라, 해당 일정에 **포지션 규모를 줄이기 위한**
사전 경고다. 일정은 미리 확정돼 있으므로 실시간성이 필요 없고, 판단이 아니라 리스크 조절이므로
검증 가능하다. Phase 8 이후 선택 구현.

## 결과

- 뉴스 관련 요청은 이 문서를 근거로 되묻는다.
- 캘린더 기능을 구현하게 되면 "예측이 아니라 규모 축소 트리거"라는 목적을 벗어나지 않는지
  기준으로 삼는다.
